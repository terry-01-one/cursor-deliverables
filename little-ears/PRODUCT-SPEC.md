# Little Ears（小耳朵）家庭版 · 产品定稿

> 状态：PM 定稿（可直接研发）  
> 适用：自家 5–6 岁孩子 · 电脑端微信小程序 · 无商业化

---

## 1. 产品一句话

每天在电脑上打开小程序，孩子自己点完一节 8–10 分钟的「听音选图 + 轻松跟读」，学会几个生活单词；家长打开「会的词」看进度。

## 2. 已拍板决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 平台 | 微信小程序，按 **PC 微信** 优化 | 你明确要电脑小程序；安装成本低 |
| 用户 | 单孩子、本机使用 | 自家用，不做账号体系 |
| 登录 | 无登录，本地存储 | 少步骤，当天就能用 |
| 商业化 | 无 | 家庭自用 |
| 跟读 | **有录音 + 鼓励语**，不做 AI 打分 | 5–6 岁先敢说；PC 麦环境不稳定 |
| 内容 | **先做 2 个主题完整可学**，结构预留到 6 个 | 先跑通再扩词包 |
| 图/音 | 统一内容 JSON；图用简洁插画资源，音用预置 mp3 | 可替换，不绑死供应商 |
| 家长锁 | **不做 PIN** | 家里电脑、使用者固定 |
| 时长限制 | 软提示：一节结束就停；不做强制锁屏 | 避免挫败；你在旁边也能控 |

## 3. 成功标准（你家验收）

1. PC 微信能打开，孩子能独立完成 1 节课。  
2. 无麦克风也能学完（跟读可跳过）。  
3. 关掉小程序再开，已学单词还在。  
4. 你能在「会的词」里看到图 + 英文 + 再听一次。

---

## 4. 信息架构

```text
小耳朵
├── 首页 Home
├── 上课 Lesson（多步骤同一页切换）
├── 结束 Celebration
├── 会的词 Words
└── 复习 Review（从已学词出题）
```

底部不放复杂 Tab：首页用大按钮进入即可；「会的词」「复习」做次级入口。

---

## 5. 主流程

```text
1. 打开小程序 → 首页
2. 点「开始今天」→ 上课页
3. 词 1…6：播放发音 → 四选一图片
   - 选对 → 鼓励 → 下一词
   - 选错 → 自动再播；第 2 次仍错 → 亮出正解 → 下一词
4. 短句 1…2：听句 → 选图 → 跟读（可跳过）
5. 结束页：贴纸 + 今日单词 →「回首页」
6. 存储：日期、完成状态、掌握词 id 列表
```

分支：
- 今日已完成 → 主按钮文案改为「再复习一次」进入 Review  
- 麦克风拒绝 → 跟读步显示「说说看（可跳过）」  
- 音频加载失败 → 按钮「再试一次」；仍失败可看图硬学并记日志

## 6. 逐屏说明

### 6.1 首页 Home

- **Goal**：一键开课；次要去复习/词表  
- **布局（上→下）**  
  1. 标题「小耳朵」+ 副标题「今天也来听一听」  
  2. 今日状态条：未完成 / 已完成（星星）  
  3. **主按钮**：开始今天 / 再复习一次  
  4. 次要：会的词 | 换主题（仅已解锁主题）  
- **主 CTA**：开始今天  
- **状态**  
  - loading：读本地进度  
  - empty：首次进入，主按钮「第一次冒险」  
- **文案**  
  - 主按钮：`开始今天`  
  - 完成：`今天真棒，去复习也可以`

### 6.2 上课 Lesson

- **Goal**：完成今日词+句，全程大点击区  
- **布局**  
  1. 顶栏：进度点 `●●○○○○` + 可弱化的「下次再学」（二次确认）  
  2. 中部大图区（选图题为 2×2 四宫格）  
  3. 喇叭按钮「再听一次」  
  4. 跟读步：大麦克风按钮 + `跳过`  
- **规则**  
  - 单屏只做一件事  
  - PC 上卡片最小点击边长约 120px 逻辑像素  
- **状态**：播放中禁用重复狂点；选中后 0.8s 内锁点击防误触  

### 6.3 结束 Celebration

- **Goal**：正向反馈并落下学习记录  
- **布局**：贴纸动画 → 今日 6 词横滑 → 按钮 `回首页`  
- **数据**：写入 `lastLessonDate`、合并 `learnedWordIds`

### 6.4 会的词 Words

- **Goal**：家长/孩子复习已掌握词  
- **布局**：网格卡片（图+英文）；点卡片播放音频  
- **空态**：`还没有单词，先去开始今天吧`

### 6.5 复习 Review

- **Goal**：从已学词随机 6 题听音选图（无新词）  
- **入口**：首页在「今日已完成」时主按钮进入  
- **若已学词 < 4**：提示 `再学一天就能复习啦` 回首页

## 7. 内容规格（定稿）

### 7.1 主题顺序

| 顺序 | 主题 ID | 名称 | MVP |
|---|---|---|---|
| 1 | animals | 小动物 | ✅ 先做 |
| 2 | colors | 颜色 | ✅ 先做 |
| 3 | family | 家人 | 预留 |
| 4 | food | 食物 | 预留 |
| 5 | body | 身体 | 预留 |
| 6 | home | 家里 | 预留 |

**解锁规则**：完成主题 1 的全部单词（或完成 3 次含该主题的每日课）后解锁主题 2。家庭版可在设置里「一键解锁全部」——**家用默认两主题都可用**，降低你维护成本。

### 7.2 Animals（6 词 + 2 句）

Words: `cat, dog, bird, fish, rabbit, duck`  
Sentences: `I like cats.` / `It's a dog.`

### 7.3 Colors（6 词 + 2 句）

Words: `red, blue, yellow, green, black, white`  
Sentences: `I see red.` / `A blue ball.`

### 7.4 每日课编排算法（固定，可预期）

- 若今日未完成：从**当前主题**取尚未掌握的词优先；不足则混入已掌握词作干扰选项。  
- 新词目标 6 个；短句固定 2 个（与主题绑定）。  
- 干扰项必须同主题，避免无意义干扰。

### 7.5 内容文件约定

```text
content/
  themes/animals.json
  themes/colors.json
  audio/*.mp3
  images/*.png
```

每词字段：`id, en, zh_hint, image, audio`  
`zh_hint` 仅家长词表可用，**上课页默认不显示中文**（沉浸听辨）。

## 9. 交互与视觉原则（适合 5–6 岁 + PC）

- 主色温暖明亮（黄/天蓝），对比足够；避免闪烁高频动画  
- 一屏一个主按钮；重要按钮在窗口中下部，方便鼠标  
- 反馈：短音效 + 动效 ≤ 1s；错题不惩罚、不扣到负  
- 文案口语化、短句；上课页尽量少字  

---

## 10. 非功能

- 兼容：PC 微信小程序基础库按当前稳定版  
- 性能：内容包两主题控制在较小体积；首课可交互目标 ≤ 3s（已缓存）  
- 隐私：不采集个人信息到服务器；录音不上传（仅本地评测/回放都不强制保存）  
- 无服务端也可运行（纯前端）
